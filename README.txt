==================================================
              ПЧЁЛ (Pchel Assistant)
==================================================

Привет! Это твой настольный ИИ-ассистент. 
Он умеет болтать, открывать программы по команде, реагировать на музыку и 
озвучивать ответы голосом. 

Чтобы он заработал, нужно сделать ВСЕГО 3 ШАГА.

--------------------------------------------------
ШАГ 1. Установка «Мозгов» (Ollama)
--------------------------------------------------
Пчёл не думает сам по себе, ему нужна локальная нейросеть.
1. Скачай Ollama с официального сайта (https://ollama.com/)
2. Нажми на клавиатуре Win + R, введи cmd и нажми Enter.
3. В открывшемся чёрном окне скопируй и вставь эту команду, затем нажми Enter:
   
   ollama pull gemma4:12b
   
   (Подожди, пока скачается модель, это около 8 ГБ. Окно само покажет 
   прогресс. Когда всё скачается, можешь закрыть CMD).

--------------------------------------------------
ШАГ 2. Запуск Пчла и озвучка
--------------------------------------------------
1. Создай папку на рабочем столе и перемести туда экзешник который скачал
2. Запусти файл Pchel.exe (двойным кликом).
3. При первом запуске он попросит API-ключ Fish Audio. 
   Это нужно для того, чтобы он говорил голосом.
4. Как получить ключ Fish Audio:
   - Зарегистрируйся на сайте fish.audio (это бесплатно).
   - Зайди в раздел "API Keys" (Ключи API).
   - Нажми "Create New Key", скопируй ключ.
   - Вставь его в поле под Пчлом и нажми Enter.
   
   (Если не хочешь заморачиваться с ключом, просто закрой поле ввода. 
   Пчёл будет работать и писать текстом, просто без голоса).

--------------------------------------------------
ШАГ 3. Как с ним общаться
--------------------------------------------------
- Двойной клик по Пчёлу — открыть/закрыть поле для ввода текста.
- Зажми левую кнопку мыши на Пчёле — чтобы перетащить его в другое место.
- Правая кнопка мыши (ПКМ) по Пчёлу — открыть меню (выключить полеты, 
  выключить музыку, сменить API-ключ или закрыть программу).

Что можно ему писать:
- Обычные вопросы: "Как дела?", "Расскажи анекдот".
- Команды для запуска: "открой стим", "открой дискорд", "открой браузер".
- Команды для закрытия: "закрой стим", "закрой хром".

--------------------------------------------------
Если что-то не работает:
--------------------------------------------------
- Если Пчёл пишет "Не вижу Ollama": значит, ты не установил Ollama или не 
  запустил её (попробуй перезагрузить компьютер после Шага 1).
- Если пишет "Ollama не нашла модель": значит, ты не ввёл команду 
  "ollama pull gemma4:12b" в Шаге 1.
- Если нет голоса: значит, Fish Audio не принял ключ, или у тебя закончились 
  бесплатные кредиты на озвучку (они обновляются раз в месяц).
- Если антивирус ругается на Pchel.exe: это ложная тревога. Нажми 
  "Подробнее" -> "Выполнить в любом случае" (PyInstaller часто пугает антивирусы).

Приятного общения!
